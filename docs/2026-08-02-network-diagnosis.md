## 证据 1：DIRECT 直连失败（不经过订阅节点）

失败的目标域名（全部是国内网站）：
- `marscode.cn`（字节跳动）
- `zijieapi.com`（字节跳动）

典型错误：
```
dial DIRECT (match GeoSite/cn) --> marscode.cn:443 error:
  dial tcp 183.240.235.46:443: connectex:
  A socket operation was attempted to an unreachable host.
```

**关键逻辑：DIRECT = 本地直连 = 不经过订阅节点。直连失败 = 本地网络问题。**

**每次核心重启 → 所有连接全断（4条 WebSocket + 国内 + 国外）。**

## 故障链

```
WiFi 本地网络波动（间歇性）
    ↓
DIRECT 直连国内失败（unreachable host）
    ↓
Clash 检测到网络变化 → 刷新代理守卫 → 核心重启
    ↓
所有连接全断（4条 WS + 国内 + 国外）
    ↓
WiFi 恢复 → 全部重连 → 正常
    ↓
周期性复发
```
