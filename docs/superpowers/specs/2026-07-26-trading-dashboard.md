# SysTrader Dashboard — 可视化监控面板设计

> 日期: 2026-07-26 | 基于架构: docs/superpowers/specs/2026-07-04-trading-system-architecture.md

## 定位

FastAPI + React (Vite) + Recharts 构建的实时监控面板，WebSocket 推送数据。

## 页面结构

**顶部状态栏**: 系统名称 + 运行状态指示灯（绿/黄/红）

**四张指标卡片**: 账户权益、持仓数、保证金率、今日盈亏

**左半区 — 当前持仓**: 表格显示每个持仓的标的、方向、数量、入场价、标记价、未实现盈亏

**右上半区 — 最近信号**: 按时间倒序的信号列表（标的、方向、信念值、时间）

**左下半区 — 模块状态**: 6 个模块的健康指示灯（绿=正常、黄=告警、红=异常）

**右下半区 — 控制按钮**: 运行中 / 暂停 / 紧急平仓

## 数据流

```
FastAPI WebSocket (/ws) ──→ React 前端
  ├── 每 1s 推送: 账户状态、持仓、标记价格
  ├── 事件驱动: 信号生成、订单成交、风控拒绝
  └── 心跳: 模块健康状态
```

## 技术栈

| 层 | 选型 |
|---|------|
| 后端 | FastAPI |
| 前端 | React 18 + Vite |
| 图表 | Recharts |
| 样式 | TailwindCSS |
| 实时通信 | FastAPI WebSocket |
